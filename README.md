# PC지우개 (PC Eraser)

학교를 옮기거나 교실을 바꿀 때, 업무용 PC에 남은 **개인 로그인·브라우저 정보**를 안전한 순서로 정리하도록 돕는 도구입니다. (만드는 중)

## 계획
1. **웹 체크리스트**: 무엇을, 어떤 순서로, 어디서 지우는지 안내합니다.
2. **점검 프로그램 (읽기만)**: 이 PC에 무엇이 남아 있는지 보여 줍니다. 아무것도 지우지 않고, 결과를 어디로도 보내지 않습니다.
3. **선택 정리**: 항목마다 물어본 뒤 지웁니다.

## 꼭 알아 두세요
- 이 도구는 확인된 항목만 보여 드립니다. **모든 개인정보가 삭제되었음을 보증하지 않습니다.**
- 학교·교육청의 정보보안 지침을 먼저 따르세요.
- 대상: Windows 10/11
